# PRIJIT SPORT - ระบบจองสนามฟุตบอล 7 คน

ระบบจองสนามฟุตบอล 7 คนของ PRIJIT SPORT ที่ทำงานบนเว็บ:

ฝั่งลูกค้าใช้ index.html และ app.js เพื่อเลือกสนาม/วัน/เวลา ทำรายการจอง และอัปโหลดสลิปชำระมัดจำ 30%
ฝั่งพนักงานใช้ staff-login.html และ staff-panel.html เพื่อจัดการสถานะการจอง ยืนยันการรับเงิน ตารางสนาม รายงานสรุป รวมถึงจัดการรูปภาพ/กิจกรรม

โปรเจกต์เป็นเว็บแบบ Static (HTML/CSS/JS) แต่ใช้ Firebase (Auth + Realtime Database) เป็นฐานข้อมูลหลัก

หน้าหลักของระบบ

1) index.html (ฝั่งลูกค้า)

แสดงข้อมูลสนาม กฎระเบียบ รูปภาพ และข่าวสาร
Login / Register ผ่าน Firebase Authentication
จองสนามฟุตบอล 7 คน

เลือกสนาม (มี 6 สนาม)
เลือกวันที่ (ระบบกำหนดจองล่วงหน้าได้ไม่เกิน 30 วัน)
เลือกช่วงเวลา (07:00 - 20:00 โดยจัดเป็นช่วง 1 ชั่วโมง)

ตรวจสถานะ "ว่าง/ไม่ว่าง" ของแต่ละช่วงเวลาผ่าน node availability/...
ยืนยันการจอง → แสดง QR PromptPay และให้แนบสลิปเพื่อชำระมัดจำ (30%)
หลังอัปโหลดสลิป ระบบจะสร้างรายการจองใน node bookings/...
ตรวจสอบรายการจองของตนเองใน checkBookingSection

แสดงสถานะ เช่น รอตรวจสอบ / อนุมัติแล้ว / กำลังใช้สนาม / เล่นเสร็จแล้ว
รองรับ ชำระค่าสนามคงเหลือ และ ต่อเวลา (Extension) ผ่าน Modal
รองรับการ ยกเลิกการจอง พร้อมลบ mirror data ให้สอดคล้อง

2)staff-login.html (เข้าสู่ระบบพนักงาน)

Login ผ่าน Firebase Auth
ตรวจสอบสิทธิ์ด้วย users/{uid}.role === 'staff'
ถ้าไม่ใช่ staff จะ logout และแสดง error
เมื่อผ่านสิทธิ์จะ redirect ไป staff-panel.html

3)staff-panel.html (Staff Panel / Admin)

มีหลายแท็บสำหรับงานจัดการ:

จัดการการจอง
ตารางสนาม
คืนมัดจำ
รายงานสรุปผล
จัดการรูปภาพ (Gallery)
จัดการกิจกรรม/ประกาศ (Activities)

ฟังก์ชันสำคัญที่รองรับในโค้ด:

อนุมัติ/ปฏิเสธ/ยกเลิกการจอง
ยืนยันรับเงินค่าสนามคงเหลือ → เปลี่ยนสถานะเป็น playing
ทำเครื่องหมายเล่นเสร็จแล้ว → เปลี่ยนสถานะเป็น completed และลบอัตโนมัติหลัง 24 ชม.
ทำรายงาน (Report) แบบรายวันผ่านปฏิทิน

โครงสร้างข้อมูล (Firebase Realtime Database)

จากการอ่าน app.js และ staff-panel.html โครงสร้างหลักประกอบด้วย:

users/{uid}: ข้อมูลผู้ใช้ (username/fullname/phone/role)
bookings/{bookingId}: รายการจอง
availability/{field}/{date}/{time}: กระจกสถานะว่าง/ไม่ว่าง (ใช้ลดการดึงข้อมูลส่วนตัว)
user_bookings/{uid}/{bookingId}: index ของรายการจองรายผู้ใช้
booking_locks/{field}_{date}_{time}: กลไกล็อกเพื่อกัน race-condition ตอนจอง/ต่อเวลา
refunds: ข้อมูลการคืน/หักมัดจำที่บันทึกโดยพนักงาน
cancellation_log: สถิติ/บันทึกการยกเลิกโดยลูกค้า
gallery: รูปภาพแกลเลอรี่
activities: ข่าวสาร/กิจกรรม

ฟีเจอร์หลัก (ตามพฤติกรรมในโค้ด)

จองสนามออนไลน์

เลือกสนาม/วัน/เวลา
เช็คว่างแบบเรียลไทม์ผ่าน availability
กันการจองซ้ำด้วย booking_locks

ชำระมัดจำ 30%

แสดง QR PromptPay
อัปโหลดสลิป (JPG/PNG ไม่เกิน 5MB)
ระบบมีตัวจับเวลา (ชำระภายใน 15 นาที)

ชำระค่าสนามคงเหลือ

ลูกค้าส่งยอดคงเหลือเมื่อถึงวันที่จอง
พนักงานยืนยันเพื่อเปิดสนาม (เปลี่ยนสถานะเป็น playing)

ต่อเวลา (Extension)

ตรวจช่วงถัดไปจาก availability
ใช้ booking_locks และสร้าง booking สำหรับช่วงต่อเวลา
จัดการโดยพนักงาน

อนุมัติ/ปฏิเสธ/ยกเลิก
ยืนยันการรับเงินคงเหลือ
ลบอัตโนมัติหลังเล่นเสร็จ (24 ชม.)
คืน/หักมัดจำผ่าน refunds
ไฟล์สำคัญในโปรเจกต์
index.html : หน้าเว็บฝั่งลูกค้า
app.js : ลอจิกฝั่งลูกค้า (จอง/ชำระ/ตรวจว่าง/extension)
staff-login.html : Login พนักงาน
staff-panel.html : Staff Panel / Admin
styles.css : สไตล์
qr-promptpay.png : QR สำหรับชำระมัดจำ
