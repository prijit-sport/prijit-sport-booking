🔧 Migration Tool — เติม availability / user_bookings

สำหรับ staff เท่านั้น ใช้ครั้งเดียวหลัง deploy Firebase Rules ชุดใหม่ที่แยก node availability/user_bookings ออกจาก bookings

⚠️ อ่านก่อนใช้งาน:
1. Script นี้จะอ่านทุก booking ที่มีอยู่ในระบบ แล้วสร้าง entry ที่ขาดหายใน availability และ user_bookings ให้ครบ
2. เป็น idempotent — รันซ้ำได้หลายครั้งโดยไม่ทำข้อมูลซ้ำ/พัง (เช็คก่อนเขียนทุกครั้ง)
3. แนะนำให้กด "🔍 ตรวจสอบก่อน (Dry Run)" ดูตัวเลขก่อนเสมอ ค่อยกด "▶️ เริ่ม Migration จริง"
4. ทำ Backup ข้อมูล (Firebase Console → Realtime Database → ⋮ → Export JSON) ก่อนรันจริงเสมอ

สถานะปัจจุบัน

จำนวน booking ทั้งหมด-
Booking ที่ยังไม่มี availability entry-
Booking ที่ยังไม่มี user_bookings entry-
Booking ที่ข้อมูลไม่ครบ (ไม่มี field/date/time/userId)-
